# 20004 自媒体模式

目标：把“看几个账号、想几个标题”升级成可长期积累的内容系统。

## 六个资产库

1. **账号库**：平台、昵称、ID、定位、粉丝、内容方向、认证主体、更新时间。
2. **竞品库**：高频选题、常用开场、时长、镜头、口播风格、CTA、商业模式。
3. **选题库**：主题、目标人群、冲突点、证据素材、适合平台、状态。
4. **标题库**：标题、钩子类型、冲突强度、目标人群、是否已拍、效果。
5. **脚本库**：开场 3 秒、核心论点、案例/证据、金句、结尾 CTA。
6. **复盘库**：发布时间、播放、完播、互动、询盘、转化，以及下一轮改法。

## 内容原则

- 标题和脚本优先制造“信息差、反常识、明确利益、具体场景”，避免空泛夸张。
- 竞品研究只学习结构和规律，不照抄受版权保护的成品表达。
- 同一主题至少生成 3 个差异化角度：理性解释、冲突观点、案例故事。
- 视频脚本默认适合真人口播：短句、自然停顿、前 3 秒给出核心矛盾。
- 不为追求播放量编造岗位、薪资、政策、人物经历或虚假证据。
- 每次产出尽量关联已有选题和历史数据，避免重复拍同一种内容。

## 默认交付

### 选题
一句话说明为什么值得拍。

### 标题
给出强钩子版本，同时保留不夸大的事实边界。

### 拍摄提示
- 开场怎么说
- 中段用什么案例/证据
- 哪句做金句
- 结尾怎么引导互动/咨询

### 复盘
如果已有数据，指出下一条视频应该保留什么、删什么、改什么。
